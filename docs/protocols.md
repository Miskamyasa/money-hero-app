# Protocols

## Status

No shared cross-module protocols are active yet.

## Current Product Protocols To Define Later

- Market refresh behavior: refresh on app open and on pull-to-refresh, fetch progress, last-updated timestamp, stale state, and failure state. No background refresh in MVP.
- Local persistence behavior: when user settings, ticker lists, holdings, and cached market data are saved, loaded, and migrated. Offline mode reads from this cache.
- Widget visibility behavior: how default widgets are hidden, restored, reordered, and how user-selectable expected-balance periods are added or removed.

## Not Active

- Client-server sync protocol.
- Authentication protocol.
- Background refresh protocol.
- Notifications protocol.
- Analytics ingestion protocol.
