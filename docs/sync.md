# Sync

## Status

Sync is not part of the current mobile product direction.

User data is local-only on device. There is no account system, backend sync, guest mode, conflict handling, or multi-device snapshot format defined.

## If Sync Is Added Later

This doc should define:

- Account identity model.
- Snapshot schema.
- Conflict and merge behavior.
- Offline write behavior.
- Import/export or migration behavior.
- Backend endpoints and auth assumptions, with exact references into `docs/contracts.md` or `../api/spec.md`.
